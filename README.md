# PyQt5 Image Viewer

A simple Image viewer using Python and PyQt5.

## Features
- View Images
- Next/Prev Image
- Keyboard Navigation
- Zoom
- Delete Images
- Rotate Images
- Mouse Wheel Zoom
- Mouse drag/pan


# Technologies
- Python
- PyQt5
